# 权衡 · AHP 决策助手

一个面向普通用户的层次分析法（AHP）决策应用。它把判断矩阵转换成自然语言两两比较，同时为熟悉 AHP 的用户提供完整矩阵入口。

## 已实现

- 编辑决策目标、评价准则和备选方案
- 逐题比较与完整判断矩阵双向同步
- 支持 `1/3`、小数及整块 Excel/CSV 矩阵粘贴
- 最大特征向量权重、CI 与 CR 一致性检验
- 不一致三元关系提示
- 方案综合排名和贡献分解
- 单准则敏感性分析
- 浏览器本地自动保存，以及 JSON 导入、导出
- 响应式轻拟物界面与键盘可操作控件

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

访问终端输出的本地地址。生产构建：

```bash
npm run build
```

## 发布到 GitHub，通过网址使用

已提供 GitHub Pages 自动发布流程，无需另外购买服务器。按照 [GitHub Pages 发布说明](GITHUB_PAGES.md) 上传源码并启用 Pages 后，即可分享生成的网址。

```bash
npm run build:github -- --base-path /你的仓库名
npm run package:github
```

静态网页生成在 `out/`；可上传的源码包生成在 `outputs/`。默认的 `npm run build` 仍用于现有 Sites 部署。

## 计算约定

- 单元格 `aᵢⱼ` 表示行项目 `i` 相对列项目 `j` 的重要程度。
- 判断矩阵满足 `aᵢᵢ = 1`、`aⱼᵢ = 1 / aᵢⱼ`。
- 权重使用 Perron 最大特征向量的幂迭代计算。
- `CI = (λmax - n) / (n - 1)`，`CR = CI / RI`。
- 默认以 `CR < 0.10` 作为建议的一致性参考线；两项比较无需检验 CR。
- 方案总分为各叶准则全局权重与方案局部优先度乘积之和。

应用输出的是当前结构和判断下的相对优先度，不代表成功概率或客观上的绝对最优。
